# superstore-analysis
Анализ продаж розничной сети, взятых из kaggle (Excel, Power Query, SQL/PostgreSQL)
— Обработал и объединил 51 тыс. заказов из 3 источников в Excel (Power Query, Merge Queries) и продублировал в PostgreSQL (JOIN); нашёл и исправил ошибку данных (некорректный формат дат при импорте CSV).
— Построил дашборд с KPI и срезами в Excel; повторил ключевые агрегаты через SQL (GROUP BY, JOIN, CASE, подзапрос, оконная функция RANK) — результаты сошлись в обоих инструментах.
— Выявил и количественно обосновал причину убыточности категории Tables (скидки свыше 30-40%, повышенная доля возвратов), сформулировал рекомендацию.
